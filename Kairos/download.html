IMPORTANT! How to install:

  1. Download & Extract: Download the extension ZIP file using the button above and extract its contents into a dedicated folder on your computer. If you cloned the repository via GitHub, make sure you have the repository folder ready.
  2. Open Extensions Page: Open your Chromium-based browser (Google Chrome, Brave, Edge, etc.) and navigate to chrome://extensions/ in your address bar.
  3. Enable Developer Mode: Look at the top-right corner of the Extensions page and toggle on the switch for Developer mode.
  4. Load the Extension: Click the Load unpacked button that appears in the top-left corner.
  5. Select Folder: In the file picker window, select the folder containing the extracted Kairos extension files (the folder containing your manifest.json).
  6. You're All Set! Kairos will now appear in your list of installed extensions and is ready for use. Pin it to your toolbar for easy access!
