What Kairos Blocks Detection For:

  • Tab switching/minimizing
  • Window focus loss
  • Window resizing
  • Fullscreen exiting
  • User inactivity idle counters
  • Copy and paste detection

What's the use case?

    Kairos is built to prevent the tracking of the telemetries listed above, which in theory could be used to enable someone to cheat on a browser exam that relies on the simple client-side browser API calls, that (public) schools pump millions of dollars into....Although nobody should EVER never ever cheat on their exams in a gazillion googolplexian years!
